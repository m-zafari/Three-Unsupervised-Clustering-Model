# Three-Unsupervised-Clustering-Model
In this project, we create the following three data samples:\
**Noisy curcles**\
**Noisy moons**\
**Isotropic gassian blobs**

Second, we will run the following algorithms on these datasets and plot the results.\
**K-means**\
**Agglomerative Clustering**\
**Density-based spatial clustering (DBSCAN)**

Finally, we will calculate the following metrics:\
**Rand index**\
**Jaccer index**\
**Silhouette index**\
**Dunn index**\
\
\
**Note**: The black color in the data plot indicates noisy data after applying the desired clustering algorithm.
